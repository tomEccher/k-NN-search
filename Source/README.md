Copy this folder that contains all the sources to compile

Run 'make' or 'make sharedMake' for shared memory applications

Run 'make aosMake' for sequential, pThread and OMP executions in distributed memory systems

Run 'make saoMake' for AVX and AVX+pThread executions in distributed memory systems

NB: the number of elments in MPI execution should be a multiple of the number of MPI processes
